# Human Gesture Recognition

End-to-end pipeline that recognises five smartphone-interaction gestures (`scroll-up`, `scroll-down`, `swipe-left`, `swipe-right`, `texting`) from a wrist-worn **Mbientlab MetaMotionR** IMU (Bosch BMI160 - 3-axis accelerometer + 3-axis gyroscope, sampled at 100 Hz).

The system loads raw `.csv` recordings, persists them in MongoDB, segments them with a sliding window, extracts time/frequency features and trains two classifiers (`SVM-RBF` and `RandomForest`) under two pipelines (raw windowed signal vs. engineered features).

---

## 1. Main functionalities

| Component | What it does |
|---|---|
| [`utils.py`](utils.py) | Pure functions for the data pipeline: filename parsing, acc/gyr pairing, `merge_asof` alignment, Butterworth lowpass, MongoDB connection and document insertion, sliding window, feature extraction, ANOVA ranking, correlation pruning, sensor-grouped scaling, classifier training and grid search. |
| [`utils_visual.py`](utils_visual.py) | Static-PNG plot helpers: 3- and 6-axis per-gesture grids across users, EDA distributions (KDE + histograms, class durations, window-per-class counts), instance time-domain / 3D / heatmap views, PCA scatter, classifier evaluation with confusion matrix. |
| [`aiot_dataset_creation_sample.ipynb`](aiot_dataset_creation_sample.ipynb) | Orchestrates the raw CSV → merged + filtered → MongoDB pipeline and saves one figure pair per session. |
| [`aiot_project_eda_segmentation.ipynb`](aiot_project_eda_segmentation.ipynb) | EDA, sliding-window segmentation, outlier removal, train/test split caching. |
| [`aiot_project_time_series.ipynb`](aiot_project_time_series.ipynb) | Modelling on raw windowed signals with `Pipeline + GroupKFold + GridSearchCV`. |
| [`aiot_project_feature_engineering.ipynb`](aiot_project_feature_engineering.ipynb) | Feature extraction, correlation pruning, PCA diagnostics, modelling. |
| [`config.yml`](config.yml) | All runtime parameters (DB URI, paths, users, sliding window, filter, scalers, classifier grids). Generated locally from [`config.yml.template`](config.yml.template); **gitignored**. |

The two utility modules expose **pure functions** only. The notebooks contain orchestration code.

## 3. Setup

### 3.1 Python environment

```bash
# clone the repo, then:
python -m venv .venv
# Windows
.\.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

Python **3.11+** is required.

### 3.2 MongoDB

Install MongoDB Community Edition ([docs](https://www.mongodb.com/docs/manual/administration/install-community/)) and start the daemon **before** running any notebook:

| OS | Start command |
|---|---|
| Windows | `net start MongoDB` |
| macOS (brew) | `brew services start mongodb-community` |
| Linux (systemd) | `sudo systemctl start mongod` |

Optional GUI: [MongoDB Compass](https://www.mongodb.com/products/tools/compass) for inspecting the inserted documents.

### 3.3 Configuration

Copy the template and edit if needed:

```bash
cp config.yml.template config.yml
```

The defaults in [`config.yml`](config.yml) work out of the box for a local MongoDB instance and the `./data` folder. Keys you may want to change:

| Key | Meaning |
|---|---|
| `client` | MongoDB URI (default `mongodb://localhost:27017/`). |
| `db` / `col` | Database / collection name (`IoTSocial` / `sensor_data`). |
| `data_path` | Path to the raw CSV root. |
| `users` / `train_users` / `test_users` | Subject codes (default `a`, `b`, `s` - split `{a,b}` train, `{s}` test). |
| `sliding_window` | `ws=200`, `overlap=100`, `w_type=hann`. |
| `filter` | Butterworth lowpass `order=4`, `wn=0.2` (fc=10 Hz @ fs=100 Hz). |
| `out_figures` / `out_results` / `out_cache` | Output paths. |
| `reset_collection` | If `true`, the `aiot_dataset_creation_sample.ipynb` clears the MongoDB collection on each run (idempotent). |
| `fine_tune.param_grid_svm` / `_rf` | GridSearchCV parameter grids (note the `clf__` prefix for `Pipeline`). |

`config.yml` is **gitignored** so each contributor edits it locally.

## 4. Execution

Run the four notebooks **in this order**, with `Restart kernel & Run All`:

1. [`aiot_dataset_creation_sample.ipynb`](aiot_dataset_creation_sample.ipynb)
   - discovers raw CSVs, pairs `acc`/`gyr`, merges on `Epoch`, applies a zero-phase Butterworth lowpass, saves one 3-axis (`3axis_<gesture>.png`) and one 6-axis (`6axis_<gesture>.png`) figure per gesture class (5 of each, all three subjects side-by-side), and inserts 27 documents into MongoDB.
2. [`aiot_project_eda_segmentation.ipynb`](aiot_project_eda_segmentation.ipynb)
   - loads the documents, runs EDA, builds sliding windows, removes outliers (saved to `outputs/results/preprocessing_removed_windows.csv`), performs the subject-based train/test split and caches everything in `outputs/cache/segmented.pkl`.
3. [`aiot_project_time_series.ipynb`](aiot_project_time_series.ipynb)
   - fits `SVM-RBF` and `RandomForest` on raw windowed signals `(N, T, 6)` using `Pipeline + GroupKFold + GridSearchCV`. Saves confusion matrices and metrics.
4. [`aiot_project_feature_engineering.ipynb`](aiot_project_feature_engineering.ipynb)
   - extracts ~102 time/frequency/cross-channel features, prunes highly correlated ones, fits the same two classifiers, runs PCA diagnostics and writes `outputs/results/comparison_table.csv`.

No CLI tool - all entry points are the notebooks. Each notebook reads its parameters from `config.yml`.

## 5. Key functions (Google-style docstrings)

The full signatures and `Args` / `Returns` blocks live in [`utils.py`](utils.py) and [`utils_visual.py`](utils_visual.py). High-level overview:

### `utils.py` - Pipeline (raw CSV → MongoDB)

```python
parse_filename(name)               # → metadata dict from "{base}_{variant}_{hand}_{sr}_{sensor}_{primary}_{user}.csv"
session_key(meta)                  # pairing key (everything except `sensor`)
discover_csvs(data_root)           # rglob('*.csv'), sorted
pair_acc_gyr(csv_paths)            # → iterator of (shared_meta, acc_path, gyr_path)
load_acc_csv / load_gyr_csv        # rename Epoch,X,Y,Z → acc_*/gyr_* + monotonic-epoch fix
merge_acc_gyr(acc_df, gyr_df)      # merge_asof on Epoch, 10 ms tolerance
apply_continuous_filter(df)        # Butterworth zero-phase lowpass on the 6 axes
build_document(df, meta)           # MongoDB document with session_id, datetime, …
mongo_connect(uri, db, coll)       # MongoClient + unique index on session_id
insert_documents(coll, docs)       # idempotent insert with skip-on-duplicate
```

### `utils.py` - Segmentation, scaling, I/O helpers

```python
sliding_window_pd(df, ws, overlap, w_type, ...)    # → list of windowed DataFrames
apply_filter(arr, order, wn, filter_type)          # per-array Butterworth filter
filter_instances(...)                              # apply_filter on a list of windows
flatten_instances_df(...)                          # window-list → flat DataFrame
df_rebase(df, target_list, ref_list)               # column rename / reorder
rename_df_column_values(np_array, y, columns)      # 2D array + integer-encoded y → DataFrame
save_figure(fig, name, dpi=150)                    # → outputs/figures/<name>.png
save_results(df, name)                             # → outputs/results/<name>.csv
build_preprocessor(columns)                        # sensor-grouped ColumnTransformer (StandardScaler acc_*, RobustScaler gyr_*)
scale_and_flatten_windows(train_mask, test_mask, windows, ...)   # (alias: MixedScaling) raw-window scaling → 2D matrices
```

### `utils.py` - Feature engineering & modelling

```python
extract_features(window, fs=100)          # ~102 time/frequency/cross-channel features per window
anova_rank_features(X, y)                 # ANOVA F-statistic ranking
correlation_diagnostic(X, threshold=0.9)  # Pearson + Spearman + high-pairs table
find_highly_correlated(X, anova_ranking, threshold=0.95)   # features to drop
evaluate_classifier(y_true, y_pred)       # accuracy / precision / recall / f1_{weighted,macro}
train_classifiers(model_names, X_tr, y_tr, X_te, cfg)      # (alias: TrainAllMLs)
tune_feature_classifier(model_name, X_tr, y_tr, groups, cfg)   # (alias: Fine_tuning) GroupKFold + GridSearchCV
```

### `utils_visual.py`

```python
# Per-gesture grids across the three subjects (used by Phase 2 EDA)
Plot_3axis(all_users_dicts, out_dir=None)              # 4×3 grid (thumb/index × acc/gyr × user) per gesture
Plot_6axis(all_users_dicts, out_dir=None)              # 2×3 grid (thumb/index × user), acc & gyr overlaid
Plot_3axis_window2 / Plot_6axis_window2                # single-gesture variants
load_data_for_visualization(pairs)                     # nested {user → gesture → finger → DataFrame}

# EDA distributions
plot_average_durations(df_all)                         # stacked bar of mean session duration per class
plot_signal_histograms(df_all)                         # KDE + histogram per (gesture, finger)
plot_windows_per_class(all_labels)                     # window count per class after segmentation

# Instance / generic helpers
plot_instance_time_domain(df)                          # time-domain plot of a single window
plot_instance_3d(df, axes_list)                        # 3D scatter of a single window
plot_np_instance(np_array, columns_list)               # NumPy array → time-domain plot
plot_heatmap(df)                                       # seaborn heatmap of values
plot_scatter_pca(df, c_name, cmap_set="plasma")        # 2D / 3D PCA scatter

# Evaluation
plot_classifier_evaluation(model_name, y_true, y_pred, classes, cmap="Blues")   # (alias: ModelEvaluation) classification report + confusion matrix
```

## 6. Data

The 54 raw CSVs (3 subjects × 9 gesture×variant combinations × 2 sensors) are **not** committed to git - they are listed in `.gitignore` to keep the repo light.

| Field | Format / values |
|---|---|
| Filename | `{base}_{variant}_{hand}_{sr}_{sensor}_{primary}_{user}.csv` |
| `base` | `scroll-up`, `scroll-down`, `swipe-left`, `swipe-right`, `texting` |
| `variant` | `thumb` / `index` (scroll/swipe) - `two` (texting) |
| `hand` | `0` (right) / `1` (left) |
| `sr` | `100` (Hz) |
| `sensor` | `acc` or `gyr` (separate file per sensor) |
| `primary` | `0` (non-dominant) / `1` (dominant) |
| `user` | `a`, `b`, `s` |
| CSV columns | `Epoch, X, Y, Z` (raw MetaBase format) |

See [`data/README.md`](data/README.md) for the full naming convention.

> **Cloud link:** the raw recordings are shared with the course staff via the team's drive; ask one of the contributors for the link if you need the dataset to reproduce the results.
